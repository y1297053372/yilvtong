## 一、先建环境

### 选哪个免费方案

| 方案 | 额度 | 有效期 | 适合 |
|---|---|---|---|
| **CloudBase 免费体验版** | 3000 资源点/月 | 可续 6 个月 | 够跑这个项目 |
| **微信 AI 小程序成长计划** | 6 个月个人版 + **10 亿混元 Token** | 报名起 6 个月 | **AI 功能必需** |

**两个都申请**。成长计划的关键在于那 10 亿 Token——没它，文书 AI 生成功能直接不可用；免费体验版的 3000 点/月不含大模型 Token 额度。

⚠️ **一个必须知道的规则**：小程序**发布上线后**，免费环境的到期时间会变更为**上线后第 15 天**，到期不转付费就销毁。你是发布过正式版的，所以免费环境只是「15 天窗口」——够评审期用，但不是长期方案。要长期跑就得转付费（基础套餐 ¥19.9/月）。

### 操作

1. 打开 [CloudBase 购买页](https://buy.cloud.tencent.com/lowcode?buyType=tcb)，领取免费体验版兑换码
2. 创建环境，**地域选上海**（新加坡地域部分功能不可用）
3. 数据库类型选**云数据库**（不是 PostgreSQL，代码用的是文档型 API）
4. 记下两个值：
   - **环境 ID**：形如 `cloud1-xxxxxxxxxxxx`
   - **存储 bucket 前缀**：控制台 → 存储 → 点开任一文件看 FileID，形如 `cloud://<envId>.<bucketPrefix>/<path>`，取中间那段

## 五、导入数据库

```bash
# 先预览
python tools/migrate_to_new_env.py \
    --new-env 新环境ID \
    --new-bucket 新bucket前缀 \
    --dry-run

# 确认后执行
python tools/migrate_to_new_env.py \
    --new-env 新环境ID \
    --new-bucket 新bucket前缀
```

脚本做两件事：
1. **改写 206 处** `cloud://旧环境.bucket/` → `cloud://新环境.新bucket/`（不改则图片全 404）
2. **规范化日期**：把 MongoDB 扩展 JSON 的 `{"$date": {...}}`（documents 42 处、user 6 处）转成 ISO 字符串
3. 用 `tcb db nosql execute` 分批 INSERT，每批 100 条

已用副本完整演练过：206 处引用全部改写、`$date` 清零、JSON 仍合法。

> ⚠️ 脚本会**直接改写 `数据库/*.json` 源文件**。跑之前建议先 `git commit`，出问题可回退。

## 六、部署云函数

```bash
# 逐个部署（首次会自动创建）
npx -y -p @cloudbase/cli@latest tcb fn deploy contentCheck -e 新环境ID
npx -y -p @cloudbase/cli@latest tcb fn deploy encryptData -e 新环境ID
npx -y -p @cloudbase/cli@latest tcb fn deploy searchCourts -e 新环境ID
npx -y -p @cloudbase/cli@latest tcb fn deploy generateDocumentPDF -e 新环境ID
```

**两个必须配置的前置条件**：

1. **`searchCourts` 需要环境变量 `MAP_KEY`**（腾讯地图 Key）
   控制台 → 云函数 → searchCourts → 配置 → 环境变量。没配的话法院推荐会返回 `Missing Key`。

2. **`generateDocumentPDF` 依赖 pdfkit**
   ```bash
   cd cloudfunctions/generateDocumentPDF && npm install
   ```
   然后随函数一起上传。`normal.ttf` 已在目录里（10MB），不用另找。

## 九、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `ENV_ISOLATED` | 环境到期隔离 | 续费恢复 |
| 图片全部 404 | 引用未改写 / 文件未上传 | 跑迁移脚本 + 补传 |
| 法院推荐返回 `Missing Key` | 未配 MAP_KEY | 控制台加环境变量 |
| PDF 中文全是方框 | 未加载 normal.ttf | 确认字体随函数上传 |
| 云函数报 `Cannot find module 'pdfkit'` | 未 npm install | 在函数目录装依赖再传 |
| AI 润色报错 | 无混元 Token 额度 | 报名成长计划 |
| 文章列表空 | 数据未导入 | 跑迁移脚本 |
