（第四段）被告作为经营者，对其销售商品的性能、质量等核心信息负有如实告知义务。其故意告知虚假情况，隐瞒真实信息，诱使原告做出错误购买决定，该行为已构成“欺诈”。根据《中华人民共和国民法典》与《中华人民共和国消费者保护法》，原告享有知悉其购买、使用的商品或者接受的服务的真实情况的权利。被告严重违反约定内容交付商品，严重侵害了原告的消费者权益，应依法承担法律责任。

2. 虚假促销

特殊选项：
1. 请输入被告在商品销售页面或宣传广告中明确表示的优惠表述
【示例：原价XXXX元，促销价XXXX元，限时5折优惠】
2. 在促销前七日（重点记号）内，被告是否以所标示的“原价”成交过？
若为“是”，则弹出提示“被告不符合虚假促销的情形，请重新选择侵权情形”；若为“否”，跳出下一个选项
3. 请输被告在优惠前七日交易的实际最低价

生成文本模板：
```
第二段：被告在其商品销售页面或宣传广告中明确标示“【填入1】”等信息。然而，原告随后发现，被告的上述促销行为构成《禁止价格欺诈行为的规定》及相关司法解释所定义的“价格欺诈”。

第四段：经原告查询与核实，在该促销活动开始前七日内，被告在本交易场所（网店）对该商品的最低成交价格实际仅为【填入3】元。被告通过捏造一个根本不存在的、更高的“原价”，制造了优惠假象。原告实际上以高于优惠价格的价款购得该商品。

第五段：被告宣称的“【填入1】”等优惠幅度，是建立在上述虚构的“原价”基础上的。由于作为计算基准的“原价”是虚假的，故其所声称的优惠价、折扣幅度完全失实，属于《消费者权益保护法》所指的“虚假或者引人误解的宣传”。并且被告作为经营者，对其商品的价格信息负有如实、全面告知的法定义务。其故意虚构高价、再假意打折的行为，直接诱使原告及其他消费者误认为获得了巨大优惠，从而作出错误的购买决定。该行为完全符合 “欺诈”的构成要件，严重侵害了原告的消费者权益，应依法承担法律责任。
```

3. 虚假宣传

特殊选项：
1. 虚假宣传行为是通过哪些渠道展示并强调的？
示例：商品详情页图文、宣传视频、主播口播、客服承诺
2. 请详细阐述虚假宣传的内容
示例：
（1）承诺“使用后7天内，具有【某项具体效果，如：祛斑率高达90%】”；
（2）宣传“商品获得【某某权威机构】认证，或符合【某某国家标准】”；
（3）承诺“商品的核心成分为【某种稀缺或高价值材料，如：100%羊毛、特定芯片型号】”；
（4）虚构“商品的销售数据或用户评价，如：销量突破XX万、某位名人推荐”。
3. 请详细阐述宣传与实际不符的情况
示例：
（1）经使用/检测，完全/严重不具备所宣传的效果；
（2）经查询，并未获得所宣称的认证，或宣传的标准与实际不符；
（3）经鉴定，不含或仅含微量所宣传的核心成分；
（4）有证据证明其宣传的销量、评价系人为刷单或伪造

生成文本模板：
```
第二段：本买卖合同·是基于原告对被告（经营者）在其商品销售页面、宣传广告或直播中对“【填入通用】”所作出的具体、明确且对交易决策有重大影响的宣传承诺的信赖而订立，然而其实质却为被告在销售过程中，为确保商品竞争力与销量，实施了以下与商品真实情况完全不符的虚假宣传行为：

第三段：被告通过其【填入1】等多种渠道，向包括原告在内的不特定消费者反复、重点强调并承诺，该商品/服务具备以下核心性能、效果或资质：【填入2】上述宣传内容是对足以影响消费者订立要约的商品内容作出的具体、确定、可验证的陈述，是原告决定购买该商品而放弃其他同类商品的决定性因素，直接诱使原告作出了错误的意思表示。原告收到商品/使用服务后发现，实际情况与被告的宣传承诺严重不符。虚假宣传的法律定性：被告作为专业经营者，明知或应知其宣传内容与事实不符，仍故意告知虚假情况，其目的正是为了诱使消费者作出购买决定。该行为完全符合《最高人民法院关于适用<中华人民共和国民法典>总则编若干问题的解释》第二十一条关于欺诈的认定标准，即故意告知虚假情况，致使原告基于错误认识作出购买意思表示。因此，被告的虚假宣传已构成消费欺诈。

第五段：被告的虚假宣传行为致使原告购买符合宣传品质之商品的根本合同目的完全落空，已构成根本违约，并直接侵害了原告的知情权与公平交易权。同时严重违反了《中华人民共和国广告法》第四条及《中华人民共和国消费者权益保护法》第二十条的规定，并因符合欺诈构成要件，应适用该法第五十五条的惩罚性赔偿规定。被告应承担相应的法律责任。
```

#### 1、 商品描述与实际不符
特殊证据：
1. 商品快照（证明原本描述内容，并对不符之处进行圈画）
2. 可证明实际到手商品与描述不符的证据（例：同角度、同光线特写图，权威机构检测报告）

#### 2、 虚假促销
特殊证据：
1. 商品快照（证明购买时的优惠话术）
2. 优惠前七日内实际原价截图/朋友未被大数据杀熟的环境下查看价格
3. 商品详情页规则（截图商品详情中关于价格、促销活动的所有文字说明）

#### 3、 虚假宣传
1. 宣传页面/视频录屏（时间戳为佳），若为直播，可查看直播回放予以录屏
2. 关键内容多角度截图
3. 有资质的第三方检测报告（可选）、权威标准比对，成分表/说明书相关内容
4. 行业常识（如：一夜暴瘦十斤）

#### 4、 发货错误
1. 开箱视频（必备）
2. 错误商品实物多角度照片（建议使用水印相机）
3. 快递面单照片
4. （若已自主寄回）退货物流凭证

#### 5、 产品存在安全隐患
1. 风险存在证据（视频、图片材料与实物）
2. 第三方检测活安全评估报告
3. 采取合理避险措施的记录

#### 6、 定制类货不对板
